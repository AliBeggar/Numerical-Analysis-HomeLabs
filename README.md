# Numerical-Analysis-HomeLabs
Scilab implementations for the Numerical Analysis course (1CS, ESI 2026/2027). Covers numerical algorithms for nonlinear equations (Bisection, Fixed-Point, Newton, Secant), direct &amp; iterative linear solvers (LU, Cholesky, Jacobi, Gauss-Seidel, SOR), eigenvalue computation (Power, QR, Jacobi), polynomial interpolation, and numerical quadrature.
